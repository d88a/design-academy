# Design Academy

Premium interactive UI/UX course platform for frontend/backend developers.

- Next.js 15, React, TypeScript, Tailwind, shadcn/ui, Framer Motion
- Supabase for auth and database
- Feature-based project structure
- Modern, minimalist, premium UI design

---

## Project structure

```
/app
/components
/features
/shared
/lib
/hooks
/styles
/public
/config
```

## Quick Start
1. yarn install
2. yarn dev
